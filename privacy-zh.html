1. App 保存哪些信息、用于什么目的

Ellie Logic 在设备上保存练习进度：浏览过的题目、答案与尝试、提示使用情况、完成记录和日期、自适应难度信息、未完成练习、错题本及难度和声音等偏好。这些数据用于运行练习、恢复进度、选择合适的题目和显示学习观察。

逐题反馈单独保存在设备上，可能包含题目编号及题目内容快照、所选问题标签、自由文字备注、处理状态，以及创建和修改日期。备注供成人使用，不需要填写孩子姓名或其他个人信息。输入或保存反馈不会自动发送给开发者。

2. 账号、广告与设备权限

当前 App 无需注册账号，没有广告、第三方统计 SDK、跨 App 追踪或开发者运营的在线学习服务。我们不会通过 App 接收、出售或出租本机学习记录。App 不要求孩子填写真实姓名、邮箱、出生日期或位置。

App 不请求麦克风、相机、通讯录、照片图库或位置权限。可选朗读使用 Apple 系统语音播放，不录制声音。Apple 可能根据您的设备设置及 Apple 隐私政策 独立处理下载、诊断或备份信息。

3. 家长控制、导出与外部链接

设置、已存反馈管理与导出位于需长按并回答问题的家长门禁之后。每题下方默认折叠的反馈输入区本身不设家长门禁。门禁用于区分成人操作和儿童练习，不是账号认证，也不代表所有设备数据均已加密。

家长可以通过系统文件目标选择器，把全部已存题目反馈导出为 JSON 文件。导出包含备注、标签、状态、日期和题目信息，也包含当前筛选范围之外的已存记录。App 不会把文件自动发给开发者。如果选择 iCloud Drive 或其他文件提供商，文件可能由其上传或同步。之后主动分享文件时，内容会发给您选择的接收方。分享前请检查并移除私人信息。

家长区域包含一个可选外部链接，用于阅读独立出版商的推理题型介绍。打开链接会访问对方服务，对方可能收到普通连接信息，并按其自身政策处理数据。

4. 保留、重置与删除

学习数据在重置或移除前保存在本机，并受存储限制：最多保留 1,000 条近期作答事件、100 次近期已完成练习，以及其他进度汇总、错题本和设置。反馈单独保存，直至内容被清空或 App 数据被删除；反馈备注没有固定自动到期时间。

家长区域的“Reset all learning progress”会重置当前练习、学习历史、错题本和偏好，但会保留逐题反馈。清除某条反馈的备注并取消所有标签，可移除该条反馈。要移除 App 的本地数据，请在 iOS / iPadOS 设置中选择“删除 App”；“卸载 App”会保留文稿和数据。

设备或云备份可能按您的 Apple 设置包含 App 数据，恢复备份可能恢复旧记录，需单独管理备份。已导出的文件是独立副本；如需删除，请在所选存储位置及同步或分享位置分别处理。开发者无法远程取回或删除仅保存在您设备、备份和导出文件中的记录。

5. 儿童使用与自愿支持

Ellie Logic 是有成人参与的儿童学习 App，没有内置聊天、公开发帖，或向开发者自动发送儿童练习及反馈的功能。本网站支持渠道供家长或监护人使用。

如果主动提交 GitHub Issue，您的 GitHub 用户名、报告和附件会被开发者及公众看到。我们使用您主动提供的内容回复问题、排查故障及改进 App。请勿公开孩子姓名、照片、学校、医疗或学习记录、完整反馈导出文件、密码或其他私人信息。阅读网站不需要 GitHub 账号；提交 Issue 需要账号，并受 GitHub 规则约束。

公开报告可能作为支持历史持续保留至被移除，也可能已被他人复制。您可使用 GitHub 提供的功能编辑或删除自己的内容。向维护者请求移除时，请仅提供相关 Issue 链接，不要重复敏感内容。需要私下处理 GitHub 持有的敏感内容时，请使用 GitHub Support 或 GitHub 隐私声明中的联系渠道。我们无法移除第三方副本。

6. 本网站

本公开网站托管在 GitHub Pages。我们未加入广告、统计、追踪像素、Cookie、外部字体或第三方嵌入媒体。网页中的简单图形示例在浏览器内运行，不保存或发送您的选择。GitHub 提供服务时可能处理 IP 地址、浏览器详情等连接与服务信息，详见 GitHub 隐私声明。

7. 联系与变更

您可通过由 GitHub 账号 jiaxiaofan813-byte 维护的 Ellie Logic 支持仓库 联系负责本 App 的开发者。有关隐私或向维护者提出的删除请求，可在该公开渠道联系，但请勿附带敏感细节。这里没有发布私人支持邮箱。

本政策描述当前离线 App 实现及本网站。当处理方式改变时，我们会更新页面及日期；未来在线功能应在提供前评估并说明其处理方式。
